À propos de moiAbout meÜber mich

Je transforme des idées concrètes en outils qui fonctionnent vraiment. Mon premier projet sérieux, une carte interactive des randonnées de ma région, m'a appris à assembler données réelles, code Python et interface claire pour résoudre un problème précis. Je code avec rigueur, j'apprends vite, et je m'implique pleinement dans chaque projet qu'on me confie — aujourd'hui, je suis prêt à mettre ça au service de vos projets en freelance.

I turn concrete ideas into tools that actually work. My first serious project, an interactive hiking-trail map of my region, taught me to combine real-world data, Python code and a clear interface to solve a specific problem. I code with rigor, I learn fast, and I fully commit to every project I take on — today, I'm ready to put that to work on your freelance projects.

Ich verwandle konkrete Ideen in Tools, die wirklich funktionieren. Mein erstes ernsthaftes Projekt, eine interaktive Wanderkarte meiner Region, hat mir gezeigt, wie man reale Daten, Python-Code und eine klare Benutzeroberfläche kombiniert, um ein konkretes Problem zu lösen. Ich programmiere sorgfältig, lerne schnell und engagiere mich voll für jedes Projekt, das mir anvertraut wird — heute bin ich bereit, das für Ihre Freelance-Projekte einzusetzen.
